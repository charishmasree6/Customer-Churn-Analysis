# Customer Shopping Behavior Analysis

This is a data analytics project where I analyzed customer shopping behavior using Python, SQL and Power BI.

The main aim of this project is to understand how customers purchase products, which categories perform well, how discounts and subscriptions affect purchases, and what patterns can be found in the data.

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SQL
- Power BI
- Jupyter Notebook

## Project Files

- `Customer_Shopping_Behavior_Analysis.ipynb` - Python analysis and data cleaning
- `customer_shopping_behavior.csv` - Dataset used for the analysis
- `customer_behavior_sql_queries.sql` - SQL queries used to answer business questions
- `customer_behavior_dashboard.pbix` - Power BI dashboard

## What I Did

### Python

I started by loading and exploring the customer shopping dataset using Python.

Some of the steps I worked on:

- Checking the dataset
- Handling missing values
- Checking duplicates
- Cleaning the data
- Changing data types where required
- Exploring customer and purchase patterns
- Creating visualizations

The Python analysis is available in the Jupyter Notebook.

### SQL

After preparing the data, I used SQL to answer different business questions.

Some of the analysis includes:

- Customer purchase behavior
- Product category performance
- Customer segments
- Purchase frequency
- Discounts
- Customer ratings
- Subscription behavior
- Payment methods

The SQL queries are available in `customer_behavior_sql_queries.sql`.

### Power BI

I also created a Power BI dashboard to make the analysis easier to understand.

The dashboard contains different charts and filters for looking at customer behavior, purchases, categories, discounts, ratings and subscription status.

The Power BI file is:

`customer_behavior_dashboard.pbix`

## Key Takeaways

From the analysis, I was able to understand:

- How customers behave across different categories
- Which products/categories have more purchases
- Differences between subscribed and non-subscribed customers
- How customers use discounts
- Customer rating patterns
- Purchase frequency and payment preferences
